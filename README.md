# map-app
Интерактивная карта с маркерами. Leaflet, OpenStreetMap + ванильный JS. Добавление/удаление маркеров, их изменение. Сохранение маркеров в localStorage
- **/src**: Исходные файлы проекта.
  - **/assets**: Статические ресурсы.
    - `styles.css`**: Стили.
  - **/js**: JavaScript файлы.
    - `main.js`: Основной файл приложения, логика работы с картами.
- **`index.html`**: Главный HTML файл.
- **/dist**: Компилированные файлы для продакшена.
- `package.json`: Описание проекта, зависимости и скрипты.
- `vite.config.js`: Конфигурация Vite.
- `README.md`: Данный файл с описанием проекта.
